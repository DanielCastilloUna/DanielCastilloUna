## 🚀 Featured work

### 🌎 Viajando Costa Rica: official website · *in development*
**Client project by CastleGT** · Astro · JavaScript · GSAP · d3-geo · Cloudflare

The official site for a Costa Rican travel brand that offers group and private tours, lodging and real estate. It will be featured to the brand's TikTok audience of 100K+ followers.

- **Interactive 3D-style globe** built with d3-geo (orthographic projection): it rotates, pauses on hover or drag, and flies to each destination to open its details card
- **WhatsApp-first conversion:** every tour and service has its own prefilled message, plus a trip **quote builder**
- **Performance budget:** images under 150 KB, TikTok players that load only on tap, and ≤ 1 MB on the first mobile load
- **Accessibility:** keyboard navigation, `prefers-reduced-motion` support, and real WhatsApp links that still work if JavaScript fails
- **Professional workflow:** feature branches and pull requests, conventional commits, and a pre-publish check script that blocks a release if any unconfirmed content slips in

*The repository is private (client work). The live link is coming soon.*
